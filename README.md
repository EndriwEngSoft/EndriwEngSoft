## About

Software Engineering student at Estácio (2024–2028) focused on backend development with Java and Spring Boot.
I build RESTful APIs with layered architecture, JWT-based auth flows, and solid test coverage — FinanceSync API alone has 101 tests covering controllers, services, and edge cases.

Currently deepening my skills in **Docker** and cloud deployment (**Railway / Render**).
Next goal: external API integration and applied AI in backend services.

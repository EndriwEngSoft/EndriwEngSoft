## Sobre

Estudante de Engenharia de Software na Estácio (2024–2028), focado em desenvolvimento backend com Java e Spring Boot.
Projeto e construo APIs RESTful com arquitetura em camadas/feature-package, fluxos de autenticação com JWT e boa cobertura de testes automatizados — só a FinanceSync API tem **101 testes** entre services e controllers.

Containerizei a FinanceSync com **Docker** (imagem publicada no GHCR) e tenho prática com **Kubernetes**.

🚧 Atualmente construindo a **LifeSync API** em **Spring Boot 4** — um sistema completo de organização pessoal e produtividade que vai muito além de um to-do list (veja em Projetos).
Próximo passo: lançar a LifeSync API e colocar um projeto rodando em produção na nuvem.

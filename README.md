## Sobre

Estudante de **Engenharia de Software** na Estácio (2024–2028), focado em desenvolvimento backend com **Java 21** e **Spring Boot**. Construo APIs RESTful com arquitetura em **feature-package**, fluxos de autenticação com **Spring Security + JWT** e boa cobertura de testes automatizados — a FinanceSync API possui **101 testes** entre services e controllers.

Containerizei a FinanceSync com **Docker** (build multi-stage, ~135 MB) e possuo manifestos de **Kubernetes** para orquestração. Sigo um roadmap contínuo focado em boas práticas de backend, testes automatizados e entrega contínua.

Atualmente construindo a **LifeSync API** em **Spring Boot 4.1** — um sistema de organização pessoal e produtividade que vai muito além de um to-do list: tarefas, hábitos com cálculo de sequência (streak), metas, estudos e finanças simples. Conta com pipeline de CI (GitHub Actions + Testcontainers) e arquitetura defensável (IDOR na camada de service, UUIDs, claims de token tipados).

Próximo passo: lançar a LifeSync API em produção na nuvem.
